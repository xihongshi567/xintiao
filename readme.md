# 薪跳 · 桌面小组件

番茄红「可爱极简」风格的**桌面小组件**，面向职场打工人。悬浮胶囊 + 展开面板两种形态，金额每秒"跳动"，提供即时心理激励。

## 快速开始

**网页版**：直接双击打开 `web/index.html` 即可（无需构建、无需安装依赖）。

**桌面版**（Windows）：运行 `src-tauri/target/release/薪跳.exe`（或安装器），获得真正的桌面悬浮组件——无边框透明、永远置顶、不占任务栏，支持托盘图标、开机自启、拖动贴屏、位置记忆。

## 功能一览

- 🥫 **悬浮胶囊**：横向胶囊（白底 + 番茄红描边），头像 + 📅 今日已赚 + 大金额；按住任意处拖拽，整体点击展开
- 💰 **实时薪资**：扣除午休后按秒计算已赚金额，每 250ms 重算，最低两位数字连续"翻页"滚动；进度条与百分比同步
- 🐾 **今日状态**：头像右下角小按钮（默认 `+`），点开浮层选 ⚡ 摸鱼中 🐟 想下班 🚌 已躺平 🛋 咖啡续命 ☕，选中后按钮变为表情
- 🎉 **节假日倒计时**：距离下一个法定节假日天数；假期中显示"正处于 X 假期中"（设置中可关闭）
- 📝 **TODO / DONE**：行内添加（回车保存、Esc 取消），勾选自动迁移到 DONE，DONE 支持删除
- 🔔 **上下班提醒**：到点弹出番茄红胶囊 Toast，整天只触发一次
- 🎨 **4 种卡通头像**：猫 / 狐狸 / 熊猫 / 小鸡（内联 SVG），设置中即时切换
- 💾 **全量持久化**：设置、状态、任务、位置、折叠态存入 `localStorage`，刷新完全保留
- 🪟 **桌面组件模式**（Tauri 宿主）：无边框透明窗口自动贴合胶囊/面板尺寸；胶囊或面板空白处拖动即移动窗口；位置自动记忆并按显示器边界钳制；点关闭隐藏到系统托盘（左键托盘显示/隐藏）；设置页可开启**开机自启**（写入注册表 Run 键）

## 桌面版构建

前置条件（一次性）：

1. [Rust 工具链](https://rustup.rs)（`rustup-init.exe`，默认 MSVC 工具链）
2. Visual Studio 2022 Build Tools，勾选「使用 C++ 的桌面开发」工作负载（提供 MSVC 编译器与 Windows SDK）
3. WebView2 运行时（Windows 11 自带）
4. 国内网络建议配置 crates 镜像源（已为你写入 `~/.cargo/config.toml`：rsproxy.cn）；若本机代理对 crates.io 不通，构建时加环境变量 `NO_PROXY=*`（一键脚本已内置）

构建：

```bash
# 方式一：一键脚本（推荐）
build-desktop.bat

# 方式二：命令行
cd src-tauri
cargo build --release
```

产物：`src-tauri/target/release/薪跳.exe`（单文件，可拷给同事直接运行）。

制作安装器（可选）：`npx tauri build`（需先 `npm i -g @tauri-apps/cli`），产物为 NSIS 安装程序。

> 浏览器模式与桌面模式共用同一份前端代码：`app.js` 检测到 Tauri 宿主（`window.__TAURI__`）时自动切换为窗口拖动、窗口贴合、开机自启等行为；直接开网页时仍为旧式页面内悬浮。桌面窗口位置单独存于 `localStorage`（键 `xintiao_desktop_pos_v1`），与网页内位置互不干扰。

## 业务规则速览

- 薪资计算精确到秒：`elapsedMin < 上班` → 0；午休中锁定；`> 下班` → 满额 100%
- 状态无弹窗提示（避免噪音）；勾选任务即迁移，无中间态
- 非法设置被阻止并提示（下班 ≤ 上班 / 午休结束 ≤ 开始 / 午休不在工作时间内 / 日薪 ≤ 0）
- 拖拽自动贴边，超出视口被拉回
